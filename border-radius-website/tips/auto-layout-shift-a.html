Wrap anything in auto layout with Shift + A

Tip 02 · 2 min read · updated June 2026

Auto layout is the single feature that separates a Figma file that fights you from one that helps you. It turns a loose pile of layers into a frame with real spacing, padding, and direction — so when content changes, the layout reflows instead of falling apart.

The thirty-second version

  1. Select the layers you want to group — a label and an icon, a stack of cards, anything.
  2. Press Shift A. Figma wraps them in an auto-layout frame.
  3. In the right panel, set the direction (horizontal or vertical), the gap between items, and the padding around them.
  4. Type a longer label. Watch the frame grow to fit instead of overlapping. That’s the whole point.

The settings that earn their keep

  • Resizing → Hug makes a frame shrink-wrap its contents. Fill makes a child stretch to the available width. Most layout bugs are just the wrong one of these two.
  • Space between (in the alignment control) pins the first and last items to the edges — perfect for nav bars and toolbars, with no spacer frames.
  • Nest it. A card is usually an auto-layout frame of auto-layout frames. Direction can differ at each level.
If it ever feels stuck: the culprit is almost always a child set to Fixed width that wants to be Hug or Fill. Check that first.

Once auto layout is muscle memory, the rest of Figma — components, variants, responsive resizing — gets dramatically easier, because it all assumes you’re using it.
